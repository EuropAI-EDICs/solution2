### 2.2 The legally binding source: agrest `Omgevingsverordening`

Service `https://agrest.geodata-utrecht.nl/rest/services/Omgevingsverordening/FeatureServer` describes itself as *"Deze service bevat de vigerende omgevingsverordening van de provincie Utrecht"* (live, 07:45Z). Querying `WHERE NAAM='Gebied windenergie'` returns 44 polygons whose attributes are exactly the grounding the PoC's cite-or-abstain rule needs:

```json
{
  "LOCATIEGROEP_NAAM": "Gebied windenergie",
  "GROEP": "windturbinegebied",
  "NAAM": "Gebied windenergie",
  "TYPE": "energievoorziening",
  "SYMBOOL_CODE": "vsz012",
  "LOCATIE_ID": "nl.imow-pv26.gebied.003000000000000000000846e119902",
  "LOCATIEGROEP_ID": "nl.imow-pv26.gebiedengroep.003000000000000000000846",
  "DOCUMENT_URL": "https://omgevingsbeleid.provincie-utrecht.nl/home?d=/akn/nl/act/pv26/2022/omgevingsverordening/nld@1089&o="
}
```

All 88 wind features (44 × `Gebied windenergie` + 44 × `Gebied kleine windturbine`) share that single AKN `DOCUMENT_URL` — the Omgevingsverordening expression `nld@1089`. The same layer also carries every other verordening designation (Natuurnetwerk Nederland, Stiltegebied, Grondwaterbeschermingsgebied, Geluidcontour, Kernrandzone, UNESCO Hollandse Waterlinies, …) with per-group DOCUMENT_URLs, making it the single authoritative exclusion source too.

**Geometry caution:** the wind set contains one 1166.5 km² province-scale polygon plus 43 small ones (0.1–0.7 km²) — the province-scale polygon must not be treated as a 'suitable everywhere' inclusion zone without the Norm Analyst reading the rule text (cite-or-abstain; flagged, not interpreted here). `Gebied kleine windturbine` has *identical* geometry (IoU 1.0000) but distinct IMOW ids — two designations sharing one map. 1/44 features is invalid as served; ET layer: 8/44 ('Nested shells') — the zone engine must run `make_valid` (V1 gate).

## 5. Download practicality & fetch strategy (Task 4)

Page math: hosted = 2000/page (11 150→6 pages per 10k), agrest = 1000/page. Wind PoC core download budget if every registry entry marked inclusion/exclusion is pulled in full:

- naive full pull of all 71 registered layers ≈ **169 MB** (dominated by: `arcgis-nnn-jun2024` 37.14 MB, `arcgis-cnossos-lden` 20.39 MB, `arcgis-cnossos-night` 20.05 MB, `arcgis-complexe-belemmeringen-39` 7.66 MB, `arcgis-harde-belemmeringen-32` 7.49 MB, `arcgis-harde-belemmeringen-23` 5.7 MB, `arcgis-planmer-v1-harde-belemmeringen` 5.12 MB, `arcgis-natura2000` 4.81 MB)
- curated PoC pull (wind subsets + exclusions actually cited by norms, `maxAllowableOffset` on coarse layers) ≈ **15–25 MB** — one-shot, no API key, well under any polite-use limit

| Layer class | Strategy (verified) |
|---|---|
| Small wind sets (≤111 feats, ≤5 MB) | single paged GeoJSON pull, `f=geojson&outSR=28992`, `resultOffset` loop until `exceededTransferLimit != true` |
| agrest legal sets | `where` subset by `NAAM`/`LOCATIEGROEP_NAAM` + `f=json&returnGeometry=true&outSR=28992`, 1000/page; convert rings client-side (mind ring orientation) |
| Big national sets (NNN 10 638 feats ≈ 83 MB unsimplified) | `maxAllowableOffset=25` (→ ~4 MB total) for constraint overlay at 25 m tolerance; exact pull only inside AOI |
| Envelope clipping | works but returns un-clipped features — combine with `maxAllowableOffset`; for exact AOI clipping do it client-side with shapely against `arcgis-provinciegrens` |
| Points (GPP 3.6–4.1k, turbines 11) | trivial paged pull |
| Geometry quality | run `make_valid` on load: 8/44 ET wind features and 1/44 OV wind features invalid as served ('Nested shells'); record per-layer validity counts as V1 evidence |

Deterministic re-execution hooks already available (V3 material): `Onderzoekslocaties_planMER_windenergie/4` 'Resterende ruimte' is the province's own published remainder polygon (2.37 MB) — the zone engine's AOI-minus-hard-constraints output can be diffed against it.
