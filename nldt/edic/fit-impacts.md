# Fit statement — IMPACTS-EDIC (one pager)

**Date:** 2026-09-20 (EuropAI M3 / framing M4–M6)  
**Relationship owners (WP4):** BZK + ICTU  
**Asset class:** Implementation Framework — orchestrator, marketplace, declarations, interoperability  
**Track:** paper track of route 3
([route-citiverse-first.md](route-citiverse-first.md)) — contact in M4,

**Fallback from M12:** Interoperable Europe ecosystem + EDIH network

## What we offer

A reusable **multi-country framework** already running in four Dutch
administrations: AppStore → Cookbook → Cook, LangGraph orchestrator, Critic
V0–V4, HITL, PROV, wallet/Keycloak identity layers, and Data Space offer
publication. Declarations are written against **OASC MIMs and the Digital
Rulebook**, not project templates. Procurement language uses Cloud and AI
Development Act **sovereignty tiers**.

## What we need

IMPACTS to treat the framework as a service in its portfolio; acceptance
criteria into the WP2/WP3 backlog at M13; a route into standardisation and
joint-procurement guidance.

## Assets in this class

- Orchestrator + Recipe / AgentPlan / ValidationReport schemas
- Trust methodology (V0–V4, cite-or-abstain, HITL)
- Marketplace publication (`services/marketplace_publish.py`)
- Data Space offers (`lake-publish-offer`, `donl-harvest-publish`)
- Source monitor (open-data continuity)
- User wallet + agent virtual wallet (consume Toolbox IM; do not rebuild IAM)

Not in this class: spatial Solution 2 recipes (CitiVERSE), GovChat-NL code
(Digital Commons).

## Proposed acceptance

1. Framework specification publishable independently of one implementation.
2. Every high-risk recipe has a MIM + Rulebook declaration
   ([declarations/](declarations/)).
3. Marketplace payload includes ValidationReport + PROV.
4. Exchange through SIMPL or logged as technical debt
   ([l2-infrastructure.md](l2-infrastructure.md)).
5. Sovereignty-tier mapping for orchestrator, lake and LLM seams
   ([sovereignty-tiers.md](sovereignty-tiers.md)).

## Reciprocity

IMPACTS gets shared building blocks and evidence for GovTech / AI-ready
services. EuropAI gets a permanent institutional home for the framework.
