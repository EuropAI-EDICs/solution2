    Recipes (Cookbook)

    A recipe is the governed playbook: ordered steps bound to process ids, with typed inputs and a riskLevel. Skills teach when; MCP tools alias one process; recipes run end-to-end via Cook / orchestrator (Critic · HITL · PROV). Click a recipe to see steps, inputs, and the linked skill.

    The term “recipe” — provenance in nLDT and the workflows it serves

    Herkomst van de term

    “Recipe” is geen metafoor die we zelf verzonnen: de term komt uit het nLDT Testbed 2026 tender, phase 2 (nldt-testbed2026-phase2-invitation-to-tender.pdf), dat de driehoek AppStore → Cookbook → Cook voorschrijft. nLDT implementeert die letterlijk: AppStore = catalog_adapter (OGC API Records), Cookbook = services/cookbook (serveert nldt/recipes/<id>.json via cookbookUri), Cook = process_adapter (OGC API Processes).
