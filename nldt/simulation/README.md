# nLDT mock simulation

Interactive visualisations for the nLDT reference implementation.

## Demos

| Demo | File | Description |
|------|------|-------------|
| **Building + zoning plan** | `building-agent-demo.html` | One building, 3D BAG, **real Rijnsweerd zoning plan** (normcards + decision table, PoC pattern) |
| Agent + 3D BAG | `agent-3d-demo.html` | Zone overlay Rijnsweerd |
| Agent flow | `agent-flow-demo.html` | LangGraph orchestrator (without 3D) |
| Overlay mock | `mock-overlay-demo.html` | Recipe-flow animation (2D mock) |

## Opening

```bash
# Option 1: open directly in the browser (no server required)
open /Users/marc/Projecten/ldttoolbox/nldt/simulation/agent-3d-demo.html
open /Users/marc/Projecten/ldttoolbox/nldt/simulation/web3d-viewer.html
open /Users/marc/Projecten/ldttoolbox/nldt/simulation/mock-overlay-demo.html

# Option 2: local server (recommended for agent-flow-run.json refresh)
cd /Users/marc/Projecten/ldttoolbox/nldt/simulation
python3 -m http.server 8090
# → http://127.0.0.1:8090/agent-3d-demo.html
# → http://127.0.0.1:8090/web3d-viewer.html
# → http://127.0.0.1:8090/building-agent-demo.html
```

### Building + zoning plan (Daltonlaan 100)

Real zoning plan **Rijnsweerd, Maarschalkerweerd** (`NL.IMRO.0344.BPRIJNSMAARSCH-0401`) with PoC pattern:

- `corpus/normcards-building.json` — cite-or-abstain normcards (article + literal quote + URL)
- `corpus/decision-table-building.json` — trace-back per renovation scenario
- `building-scenario.json` — generated by `scripts/build_daltonlaan_scenario.py`

```bash
python3 scripts/build_daltonlaan_scenario.py   # 3D BAG + corpus → building-scenario.json
cd simulation && python3 -m http.server 8090
# → http://127.0.0.1:8090/building-agent-demo.html
```

### Agent flow demo

Based on orchestrator run `7b19e922`. Shows 7 LangGraph nodes:

1. catalog_search → plan_recipe → validate_plan
2. execute_steps → validate_outputs → register_hybrid → explain

Refresh run data after a new orchestrator run:

```bash
cd nldt
PYTHONPATH=. python -m agents.orchestrator.run \
  --request "Voer spatial overlay analysis uit" \
  --recipe spatial-overlay-analysis \
  --aoi-file examples/aoi.geojson \
  --input layerAUri=file://$(pwd)/examples/layer-a.geojson \
  --input layerBUri=file://$(pwd)/examples/layer-b.geojson \
  --auto-approve-hitl \
  --output-dir data/runs/agent-flow-demo
# Then copy artifacts to simulation/agent-flow-run.json (or edit manually)
```

### Overlay mock

Click **Start simulation** to step through the recipe flow:

1. Catalog + Cookbook
2. Fetch layers A and B
3. Spatial intersection (250,000 m² overlap)
4. Statistics + validation pass

The map uses the same geometry as `examples/layer-a.geojson` and `layer-b.geojson` (RD New, mock grid).

### Agent + 3D BAG (recommended)

Combined simulation: **LangGraph orchestrator** + **3D BAG Rijnsweerd**:

1. NL request → Catalog Navigator → Recipe Planner → Critic
2. Executor runs 4 process jobs — overlay zones appear **in 3D** on BAG buildings
3. Critic validates → Hybrid Bridge exports Web3D Context
4. Explainer: summary + 10,000 m² intersection

Based on a real orchestrator run (`agent-3d-run.json`).

Refresh the run:

```bash
cd nldt && source .venv/bin/activate
PYTHONPATH=. python -m agents.orchestrator.run \
  --request "Analyseer de overlap van zone A en B in Rijnsweerd Utrecht" \
  --recipe spatial-overlay-analysis \
  --aoi-file examples/rijnsweerd/aoi.geojson \
  --input layerAUri=file://$(pwd)/examples/rijnsweerd/layer-a.geojson \
  --input layerBUri=file://$(pwd)/examples/rijnsweerd/layer-b.geojson \
  --auto-approve-hitl \
  --output-dir data/runs/rijnsweerd-agent-3d
```

### Web 3D BAG — Rijnsweerd

Cesium viewer with **real 3D BAG** buildings (LoD2.2 3D Tiles) around **Rijnsweerd, Utrecht** (~200×200 m):

- 64 buildings fetched via the [3D BAG API](https://api.3dbag.nl/)
- Overlay zones A/B + intersection (10,000 m²) for the nLDT recipe
- RD bbox: `138959–139159 E, 455606–455806 N`

Refresh data:

```bash
cd nldt
python scripts/fetch_3dbag_rijnsweerd.py
```

Sample data: `examples/rijnsweerd/` (aoi, layers, footprints, CityJSONSeq).

```bash
open simulation/web3d-viewer.html
# Requires internet (Cesium + 3D BAG tiles)
```
