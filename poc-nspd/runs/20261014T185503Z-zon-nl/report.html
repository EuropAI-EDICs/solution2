NC-ZON-01 · art. 18.18 binding conf 0.95

Solar installations may be provided for inside urban area and outside urban area only on enumerated locations (bouwvlak, stortplaatsen/infrastructuur/bedrijvigheidsterreinen, waterbassins, agrarische grond in transitie, agrarische grond with net-congestion contribution); siting outside urban area requires omgevingskwaliteiten motivation.

“1 Een omgevingsplan kan voorzien in de realisatie van een opstelling voor zonne-energie binnen stedelijk gebied. 2 Een omgevingsplan kan voorzien in de realisatie van een opstelling voor zonne-energie buiten stedelijk gebied op de volgende locaties: a. op een bouwvlak;”

Limitations & tuning

  • Zone geometry comes from pinned national open-data aliases (NL: PDOK OGC API natura2000; BE sources registered in ZONE_SOURCES are not exercised by any formalized phase-1 rule); the provincial GIO/DSO download chain is not used in this PoC.
  • No inclusion rule in the phase-1 shards carries executable zone geometry: the NL bijlage-XIV wind-concentratielocaties and the BE RUP-deelgebieden/gewestplan-SV zones have no pinned open-data alias, so every inclusion norm is routed to the V4 human-expert checkpoint and the run uses the request AOI as inclusion union (inclusionBasis=aoi).
  • Re-run the legal recon and this pipeline before using results after a new consolidation of the cited instruments (NL: CVDR709135; BE: RUP/gewestplan/VCRO).
  • Map geometry in this report is display-simplified; authoritative full-resolution geometry is zones.geojson / zones.gml in the run directory.
  • Zone algebra inputs are Douglas-Peucker simplified (tolerance recorded per run in run_summary.json tunings and per layer in the engine provenance) so district-scale GEOS overlays stay tractable.
  • programming-stage screening artifact; per-location permission assessment remains required.
